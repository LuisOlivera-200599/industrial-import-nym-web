Estado de conexión

Este panel usa Supabase Auth, products, brands, categories, subcategories, company_settings y Storage.

Storage: las imágenes se suben al bucket product-images y se guarda la URL pública en products.image_url.

Subcategorías: cada subcategoría depende de una categoría principal. Si una marca, categoría o subcategoría está siendo usada por productos, el sistema bloqueará su eliminación.
